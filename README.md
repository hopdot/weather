# HCOINX (HCXX) ERC-20 Token

**HCOINX** is an Ethereum-based ERC-20 token.

- **Symbol:** HCXX
- **Owner:** Howard Mosely (`gmo.hc93@gmail.com`)
- **Standard:** ERC-20
- **Decimals:** 18

## Deployment Guide

1. Open [Remix IDE](https://remix.ethereum.org)
2. Paste `HCOINX.sol` code and compile with Solidity v0.8.20
3. Connect MetaMask (Injected Web3)
4. Deploy with desired initial supply (e.g., 1,000,000)
5. Add the contract to MetaMask using deployed address

## Dev Tools

- `tokenViewer.html`: View total supply via Web3
- `api.js`: Node.js API exposing token metadata
